# Textile Manufacturing System — Frontend

A web-based textile manufacturing management interface built with React and Vite.

## Tech Stack

- React
- JavaScript (JSX)
- Vite
- Tailwind CSS
- React Router
- Lucide React
- Recharts

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Start the development server

```bash
npm run dev
```

### 3. Build for production

```bash
npm run build
```
